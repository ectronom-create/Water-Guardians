# 💧 حُرّاس المياه – ابتكري الحل
## منصة تعليمية تفاعلية لريادة الأعمال الخضراء والذكاء الاصطناعي للمدارس

---

## 🌟 نبذة عن المشروع
تطبيق ويب تفاعلي متكامل باللغة العربية (RTL)، مصمم خصيصاً لطالبات المدارس، يهدف إلى التوعية بمشكلة هدر المياه في البيئة المدرسية، وتحفيز التفكير الإبداعي وريادة الأعمال الخضراء وابتكار حلول عملية ذكية باستخدام التكنولوجيا والذكاء الاصطناعي.

---

## 🚀 كيفية تشغيل المشروع

### الطريقة المباشرة (Windows):
- انقري نقراً مزدوجاً على ملف: **`start.bat`**

### أو عبر موجه الأوامر (Terminal):
```bash
cd water-guardians
npm start
```

- **رابط الواجهة الرئيسية للطالبات:** [http://localhost:3000](http://localhost:3000)
- **رابط لوحة تحكم الإدارة المدرسية:** [http://localhost:3000/admin](http://localhost:3000/admin)

### 🔑 بيانات الدخول للوحة الإدارة:
- **اسم المستخدم:** `admin`
- **كلمة المرور:** `********`

## 🗺️ مراحل البرنامج ورحلة الطالبة:

1. **الصفحة الرئيسية:** ترحيب ملهم، عداد هدر المياه التفاعلي، وتسجيل اختياري سريع دون الحاجة لإنشاء حساب.
2. **المرحلة الأولى (اكتشفي المشكلة):** أسئلة تفاعلية بأنواع متعددة (اختيار من متعدد، صح أو خطأ، مواقف واقعية، أسئلة مصورة) مع تغذية راجعة وشرح تعليمي فوري ونقاط تشجيعية.
3. **المرحلة الثانية (اكتشفي الابتكارات):** بطاقات تفاعلية مصورة للحلول الخمسة (العبوات، الصنابير الذكية، كشف التسرب، الذكاء الاصطناعي، التوعية الرقمية) مع نوافذ لاكتشاف آلية عمل كل ابتكار.
4. **المرحلة الثالثة (ابتكري الحل):**
   - **الخيار الأول:** اختيار ابتكار موجود ودراسة تطبيقه في المدرسة.
   - **الخيار الثاني:** ابتكار فكرة جديدة كلياً بنموذج ابتكاري احترافي.
   - **لوحة رسم تفاعلية (Interactive Canvas):** لرسم الفكرة التوضيحية مباشرة أو رفع صورة.
   - **المساعد الذكي (AI Assistant):** يقدم نصائح وأسئلة إرشادية لكل حقل دون كتابة الحل نيابة عن الطالبة.
5. **المرحلة الرابعة (إرسال الابتكار والشهادة):**
   - إصدار كود مشاركة فريد (`WG-XXXXXX`).
   - منح الشارات الثلاث (`حارسة المياه`، `المفكرة الذكية`، `المبتكرة الخضراء`).
   - شهادة إنجاز رقمية معتمدة قابلة للطباعة والمشاركة.
   - **لوحة الشرف (Leaderboard):** لعرض أفضل الابتكارات المعتمدة وقائمة المتصدرات.

---

## ⚙️ مميزات لوحة تحكم الإدارة:
- إحصائيات متقدمة ورسوم بيانية تفاعلية (Chart.js).
- سجل الطالبات مع ميزة **«عرض الإجابات التفصيلية»** في الاختبار.
- تحكيم الابتكارات بنظام النجوم (الإبداع، الأثر البيئي، إمكانية التطبيق، التقنية).
- اعتماد الابتكارات المميزة ⭐ لتظهر في لوحة الشرف.
- إضافة وتعديل وحذف وتفعيل أسئلة التحدي وكتالوج الابتكارات.
- تصدير كامل البيانات إلى ملف Excel / CSV يدعم اللغة العربية بامتياز (UTF-8 BOM).
